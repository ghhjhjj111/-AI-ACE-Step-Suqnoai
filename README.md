## 一、和 SunoAI 核心区别

Suno 是云端在线服务，有额度、收费、有平台版权协议；ACE-Step 本地跑，整合包装好之后**离线生成**，生成音频归属自主可控，适合批量做原创歌曲、背景音乐、翻唱改编、短视频 BGM 创作。

## 二、整合包特点

✅ 一键启动，内置全套运行环境、基础模型、Gradio 网页 UI，解压即可用
✅ 低配友好，最低显存 4G 即可运行，自动适配显卡，支持 CPU 低速生成
✅ 中文优化好，支持中文歌词，文字直接生成带人声演唱的完整歌曲，歌词对齐演唱
✅ 支持多语言、多种曲风：流行、民谣、古风、说唱、摇滚、纯音乐伴奏
✅ 丰富的编辑能力：局部重绘 Repaint 改片段、只改歌词不动旋律、参考音频复刻风格、歌曲分轨提取（人声 / 伴奏分离）
✅ 支持 LoRA 微调，可以训练专属音色、专属曲风
✅ 导出 WAV 高清无损音频，无水印

## 三、核心功能

1. **文字生成歌曲（文生歌）**：输入描述，例如 “温暖治愈中文民谣，女声，吉他伴奏，节奏舒缓”，AI 自动写词、编曲、生成演唱歌曲
2. **歌词直接唱歌**：粘贴写好的歌词，选定曲风、歌手音色，一键生成对口演唱成品
3. **翻唱 / 参考音频生成**：上传一段参考音频，复刻它的风格、唱腔，生成新歌
4. **局部修改 Repaint**：歌曲某一段不满意，单独重生成这一段，不用整首重跑
5. **伴奏分离**：上传成品音乐，自动提取纯伴奏、干声人声
6. **批量生成**：批量导入多组提示词，批量出歌
7. **LRC 歌词同步生成**：自动输出歌词时间轴字幕，短视频直接使用

## 四、硬件要求

- 推荐：NVIDIA 独立显卡，6G 及以上显存，生成速度快
- 最低：4G 显存（会自动开启量化 + 内存分流，速度变慢）
- 无 N 卡：支持 CPU 模式，速度很慢，适合小样测试
